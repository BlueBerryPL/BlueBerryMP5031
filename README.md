# BlueBerryMP5031
Library for managing MP5031 USB PD port with Five Configurable PDOs and Load-Shedding. Current version: 1.0.0

Library has been tested using custom MP5031 + MP4247 + ATTINY1616 demonstration board, designed and assembled by BlueBerry.

Documentation is avaliable in doc folder.
